# 2D 版分镜：输入依据到完整 HTML

对应 Remotion Composition `SkillIntro2D`：1920 × 1080、30 fps、40 秒。五个主镜头使用 15 帧交叠淡化；完整的共用规则和渲染命令见 [storyboard-2d-3d.md](storyboard-2d-3d.md)。

## 01｜开场（00:00–00:05）

- 桌面输入物件作为背景，缓慢放大并向左移动。
- 0.35 秒后，标题“不是从一张效果图开始”淡入并向上归位。
- 素材：`remotion/public/opening-inputs.png`。

## 02｜逐项核对输入（00:04.5–00:13.5）

| 场内时间 | 焦点 | 镜头动作 |
| --- | --- | --- |
| 0–0.8 秒 | 输入全景 | 轻微推进 |
| 0.8–2.05 秒 | 分层图纸 | 移向 CAD / PDF 和楼层标签 |
| 2.05–3.3 秒 | 尺寸依据 | 移向比例尺和复尺信息 |
| 3.3–4.55 秒 | 生活需求 QA | 聚焦逐层、逐房间问题 |
| 4.55–7.4 秒 | 风格与材料 | 聚焦参考图，强调不改变户型 |
| 7.4–9 秒 | 输入全景 | 退回整体并准备转场 |

使用椭圆光影聚焦和弹簧标签，不使用土黄色矩形框。

## 03｜处理流程（00:13–00:23）

- 场内 0.8 秒起绘制进度线。
- 0.8、2.25、3.7、5.15 秒依次进入四张卡：图纸事实、逐房间说明、独立楼层基线、3D / Imagen。
- 结论固定为“每一层，都从自己的图纸重建”。

## 04｜逐层成果（00:22.5–00:32.5）

- 一、二、三层卡片依次进入，先展示整层，再于场内 2.7–3.75 秒切到重点房间。
- 一层：公共轴和玻璃厨房；二层：家庭厅、楼梯与阳台；三层：干湿分离与材料。
- 场内 6.3–7.2 秒从三层画廊切到完整 HTML。
- 随后标注独立楼层 3D、单文件 HTML、手机预览、定位留言与历史导出。

## 05｜收束（00:32–00:40）

- 完整 HTML 背景压暗并缓慢移动。
- 标题“一份 HTML，可以看 · 可以聊 · 可以继续改”弹簧进入。
- 右下角浮球轻微呼吸，呼应定位留言功能。

## 2D 校验点

- 2D 保持纸张和杂志排版，不使用 3D 发布舞台。
- 三层的整层与重点房间素材必须成对对应。
- 修改镜头后检查 0、135、390、675、960 帧及四个转场中点。
