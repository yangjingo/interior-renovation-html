# 2D / 3D 动效分镜记录

本文对应 `remotion/src/SkillIntro.tsx` 当前脚本，用于记录两支独立视频的画面、镜头运动、素材和转场。时间按 30 fps 计算；相邻主镜头使用 15 帧（0.5 秒）交叠淡化，因此时间段会有重叠。

## 成片规格

| 版本 | Composition | 时长 | 画面重点 |
| --- | --- | --- | --- |
| 2D | `SkillIntro2D` | 40 秒 / 1200 帧 | 输入证据、处理规则、逐层效果图、完整 HTML |
| 3D | `SkillIntro3D` | 30 秒 / 900 帧 | 等距模型、楼层拆分、真实切层、网页内交互 |

## 2D 分镜

### 01｜开场：从输入开始（00:00–00:05）

- 画面：桌面上的图纸、尺寸、QA 和材料参考，标题为“不是从一张效果图开始”。
- 镜头：背景缓慢放大并向左轻移；标题在 0.35 秒后淡入、向上归位。
- 素材：`public/opening-inputs.png`。
- 目的：先建立“设计从证据开始”，不抢先展示最终效果。

### 02｜输入证据逐项聚焦（00:04.5–00:13.5）

| 场内时间 | 聚焦内容 | 动效 |
| --- | --- | --- |
| 0–0.8 秒 | 全部输入 | 建立全景和轻微镜头推进 |
| 0.8–2.05 秒 | 分层图纸 | 光影聚焦 CAD / PDF 与楼层标签 |
| 2.05–3.3 秒 | 尺寸依据 | 镜头移向比例尺和现场复尺信息 |
| 3.3–4.55 秒 | 生活需求 QA | 聚焦每层、每房间和家具问题 |
| 4.55–7.4 秒 | 风格与材料 | 聚焦参考图，强调它只控制氛围、不改变户型 |
| 7.4–9 秒 | 全部输入 | 镜头退回整体，为流程页转场 |

标签使用弹簧进入和短淡出；聚焦采用椭圆光影，不使用色块框选。默认读取静态图，也可通过 `useGeneratedClips` 切换到 `clips/01-inputs-to-evidence.mp4`。

### 03｜处理流程（00:13–00:23）

- 0.8 秒起绘制进度线，至 7.8 秒完成。
- 四张流程卡依次在场内 0.8、2.25、3.7、5.15 秒进入：图纸事实 → 逐房间说明 → 独立楼层基线 → 3D / Imagen。
- 卡片从下方轻推进入；“独立楼层基线”使用深色章节卡强调。
- 固定结论：“每一层，都从自己的图纸重建。”

### 04｜逐层成果与完整 HTML（00:22.5–00:32.5）

- 前半段：一层、二层、三层三张卡依次出现，先显示整层视图；场内 2.7–3.75 秒交叉切换到对应重点房间。
- 镜头：三卡整体缓慢放大、水平轻移，单张图片做克制的 Ken Burns 缩放。
- 一层强调客厅—餐厅—玻璃厨房公共轴；二层强调家庭厅、楼梯与阳台；三层强调主卫干湿分离与材料。
- 场内 6.3–7.2 秒从楼层画廊淡化到完整 HTML；随后依次标注“独立楼层 3D、完整单文件 HTML、手机公开预览、定位留言与历史导出”。
- 素材：`public/selected-renders/`、`public/closing-output.png`；可选视频为 `clips/03-output-html.mp4`。

### 05｜2D 收束（00:32–00:40）

- 画面：完整 HTML 背景压暗，标题“一份 HTML，可以看 · 可以聊 · 可以继续改”。
- 镜头：背景缓慢移动和放大；标题在 0.45 秒后进入。
- 右下角浮球做轻微呼吸缩放，呼应方案讨论与留言功能。

## 3D 分镜

### 01｜从图纸进入空间（00:00–00:06）

- 画面：真实一层等距模型从窄裁切展开，标题“把图纸，变成可以接近的空间”。
- 镜头：模型卡由较强透视逐渐放平，缓慢推近；环境光从左向右移动。
- 素材：`public/3d-showcase/interactive-floor-1.png`。
- 约束：不再使用顶视平面贴图冒充 3D，必须看到墙体高度、楼梯和房间围合。

### 02｜逐层拆分与进入网页（00:05.5–00:15.5）

| 场内时间 | 画面动作 |
| --- | --- |
| 0–2.15 秒 | 一层模型建立；三层素材按 0.28 秒间隔逐层亮起 |
| 2.15–4.25 秒 | 三张楼层模型向不同方向拉开，形成有厚度的分层堆叠 |
| 4.1–7.15 秒 | 整组模型轻微环绕、横移并改变观察角度 |
| 7.1–8.55 秒 | 分层模型缩向左侧，右侧浏览器式 3D 页面进入 |
| 7.55 秒后 | “拖动旋转、逐层切换、锚点留言”依次出现 |

每层使用自己的 `interactive-floor-1/2/3.png`，并配置独立厚边、接触阴影、边缘高光和光线扫过。三层可以共享镜头与材质语言，但不能共享空间骨架。

### 03｜真实楼层切换（00:15–00:23）

- 0–1.8 秒保持一层；1.8–2.45 秒交叉切到二层。
- 2.45–4.25 秒保持二层；4.25–4.9 秒交叉切到三层。
- 4.9–8 秒保持三层；底部楼层按钮同步改变激活状态。
- 镜头始终轻微向右推进、向上漂移，使切层像同一观察者在检查不同模型。
- 校验重点：切换后墙体、楼梯、阳台和房间关系必须一起改变，不能只换标签或家具。

### 04｜网页交互与滚动收束（00:22.5–00:30）

- 0–1.15 秒：浏览器窗口先展示干净的一层等距模型；1.15–1.75 秒渐隐到真实 HTML 长截图。
- 1.8–6.6 秒：页面从 118 px 平滑滚动到 2580 px；6.6–7.5 秒继续滚动到 2760 px。
- 滚动条位置和页面同步，1.2–7.1 秒显示“SCROLL · 浏览完整方案”提示。
- 右侧文案为“看空间。聊设计。继续改。”，横线在 1.2–4.8 秒延展。
- 第 705 帧位于本段前部，必须显示立体模型而不是平面俯视图。

## 动效统一规则

- 所有动画由 `useCurrentFrame()`、`interpolate()` 或 `spring()` 驱动，不使用 CSS transition / keyframes。
- 时间先以秒描述，再乘以 `fps`；常规标题与卡片使用无回弹或弱回弹。
- 2D 使用纸张、杂志排版和光影聚焦；3D 使用深色舞台、透视位移、模型厚度和接触阴影。
- 图片统一通过 Remotion `<Img>` 和 `staticFile()` 加载，避免导出时出现空帧。
- 每次修改镜头、时长或素材后，同步更新本文，并至少检查开场、转场中点、各层切换及第 705 帧。
