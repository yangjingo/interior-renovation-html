# Intro Video Storyboards

Intro 明确分成两支独立视频，不使用“2D 主片中插入 3D 片段”的混合结构。完整逐镜记录见 [storyboard-2d-3d.md](storyboard-2d-3d.md)。

## 2D 版：输入到完整输出

- 时长：40 秒，1920 × 1080，30 fps。
- 视觉：原有暖色工作台、纸张、输入物件、流程卡和三层效果图。
- 叙事：输入依据 → 逐层处理 → 房间效果 → 单文件 HTML。
- 详细分镜：[storyboard-2d.md](storyboard-2d.md)

## 3D 版：从图纸进入空间

- 时长：30 秒，1920 × 1080，30 fps。
- 视觉：全新深色发布舞台、移动光影、楼层分离、视角移动和网页落位。
- 叙事：图纸变空间 → 三层独立骨架 → 真实切层 → HTML 交互。
- 详细分镜：[storyboard-3d.md](storyboard-3d.md)

两支视频共享同一项目事实，但不共享时间线。2D 负责解释完整工作流；3D 只介绍模型与交互能力。
