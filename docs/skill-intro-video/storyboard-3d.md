# 3D 版分镜：独立楼层模型与网页交互

对应 Remotion Composition `SkillIntro3D`：1920 × 1080、30 fps、30 秒。四个主镜头使用 15 帧交叠淡化；完整的共用规则和渲染命令见 [storyboard-2d-3d.md](storyboard-2d-3d.md)。

## 01｜从图纸进入空间（00:00–00:06）

- 一层等距模型从窄裁切展开，镜头缓慢推近并减弱卡片俯仰。
- 光影从左向右移动，标题为“把图纸，变成可以接近的空间”。
- 素材：`remotion/public/3d-showcase/interactive-floor-1.png`。
- 必须看到墙体高度、楼梯和房间围合，不使用顶视平面图冒充 3D。

## 02｜楼层拆分（00:05.5–00:15.5）

| 场内时间 | 镜头动作 |
| --- | --- |
| 0–2.15 秒 | 一层建立，三层素材按 0.28 秒间隔亮起 |
| 2.15–4.25 秒 | 三层模型分离为有厚度的空间卡片 |
| 4.1–7.15 秒 | 整组模型轻微环绕、横移和俯仰 |
| 7.1–8.55 秒 | 模型缩向左侧，浏览器式 3D 页面进入 |
| 7.55 秒后 | 拖动旋转、逐层切换、锚点留言依次出现 |

每层具有独立厚边、接触阴影和边缘高光；三个画面分别来自 `interactive-floor-1/2/3.png`。

## 03｜真实切换楼层（00:15–00:23）

- 0–1.8 秒：一层。
- 1.8–2.45 秒：交叉切换到二层。
- 2.45–4.25 秒：二层。
- 4.25–4.9 秒：交叉切换到三层。
- 4.9–8 秒：三层。
- 镜头全程轻微向右、向上移动，楼层按钮与画面同步。

切层必须同时改变墙体、楼梯、阳台和房间关系，禁止只换标签或家具。

## 04｜HTML 滚动收束（00:22.5–00:30）

- 0–1.15 秒先展示干净的等距模型，1.15–1.75 秒渐隐到真实 HTML 长截图。
- 1.8–6.6 秒滚动至 2580 px，6.6–7.5 秒继续滚动至 2760 px。
- 滚动条、SCROLL 提示和页面位置同步；右侧显示“看空间。聊设计。继续改。”
- 第 705 帧位于本段前部，必须保持真实模型的立体感且没有截图文字残留。

## 3D 校验点

- 检查 0、165、450、675 帧和三个转场中点。
- 逐层比较轮廓、楼梯、阳台、门窗和房间关系，确认三套独立骨架。
- 检查 705 帧、浏览器滚动终点及模型到 HTML 的交叉淡化。
- 禁止黑色遮挡块、平面俯视贴图和过曝模型进入用户成片。
