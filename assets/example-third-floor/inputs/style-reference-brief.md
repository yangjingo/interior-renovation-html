# Distilled style reference

The uploaded image is used only for observable atmosphere:

- warm, low-saturation grey concrete and mineral-plaster character;
- visible but controlled construction texture;
- low, sparse furniture with broad horizontal silhouettes;
- dark smoked timber and matte black metal accents;
- large natural-light opening with soft, directional daylight;
- quiet, restrained, soft-brutalist / wabi-sabi mood;
- warmth added through textiles and timber rather than decorative clutter.

Practical translation:

- seal retained concrete so it does not dust or chalk;
- use a protected cement-based self-levelling system only in suitable dry areas;
- use waterproof, non-slip tile or slab systems in bathrooms and exposed balconies;
- keep light layered and low-glare, usually 3000–3500 K by room function;
- avoid glossy sealer, blue-grey overcooling, distressed “fake damage,” and unusably empty staging.
