# Distilled presentation brief

Use a calm warm-editorial HTML shell:

- warm ivory canvas, dark grey-blue or warm charcoal text;
- one muted rust/coral accent used sparingly;
- serif display headings and readable humanist sans body;
- generous whitespace, hairline borders, quiet cards, and minimal shadows;
- strong page hierarchy and restrained icon use;
- technical diagrams may use a hand-drawn annotation language, but the main interface and photorealistic renders should not imitate sketch graphics.
- image and render slots use the same warm-paper frame, small type label, fixed aspect ratio, and an explicit missing-asset state instead of a blank rectangle;
- review mode uses a 48 px rust draggable pin-and-pencil orb, a dark 380 px drawer, stable area anchors, local-only storage wording, append-only history, import, and JSON / Markdown / CSV export.

The presentation layer never establishes plan facts. It only explains already verified evidence and proposals.
