# Example user constraints

## Scope

- Use the third-floor plan from the uploaded CAD-exported PDF.
- Keep and actively plan all balconies.
- The floor should feel large, calm, comfortable, and minimalist rather than densely furnished.
- Door and window dimensions may be refined as concepts; wall and opening feasibility must be checked before construction.

## Programme

- Two bedrooms.
- One study and game room.
- One large family lounge.
- Two bathrooms, with a larger main bathroom and proper dry/wet separation.
- No new kitchen function on this floor unless the drawing and user later request it.

## Style

- Use the uploaded warm rough-concrete image as the atmosphere reference.
- Combine warm grey mineral/concrete character, smoked timber, matte black metal, soft textiles, and warm layered light.
- Keep concrete visually raw but technically sealed and maintainable.

## Practical specifications

- Study desk: 1800 × 800 mm, dual-motor sit-stand base, task lamp, and concealed cables.
- Bedrooms: mattress only; retain a thin ventilated slatted or moisture-control layer below it.
- Dry floor: practical cement-based self-levelling with matte protection.
- Bathrooms and shower areas: waterproof system, closed-water test, non-slip tile, drainage falls, and glass separation where appropriate.
- Balcony systems must be exterior-rated and must not copy the indoor self-levelling build-up.
- Prefer practical domestic alternatives and clearly state what is safe to buy second-hand versus new.

## Deliverable

- Pair plan-faithful 3D previews with final room renderings.
- Include materials, budget ranges, sizes, colours, and second-hand/search keywords.
- Package all project images inside one downloadable HTML; provide a static fallback if live 3D cannot load.
