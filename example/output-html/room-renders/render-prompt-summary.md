# 一层、二层逐房间渲染提示词说明

## 生成规则

- 工具：内置 ImageGen。
- 几何依据：每张图只使用对应楼层的 CAD 平面图与该层整体 3D 底图，不复用其他楼层的空间骨架。
- 风格依据：沿用三层参考页的暖色、自然材质、克制软装与写实室内摄影表达，但按楼层功能重新设计。
- 一致性要求：门窗位置、房间边界、交通关系和主要家具尺度服从图纸；不臆造结构改动。

## 一层风格锁定

“暖石礼序极简”：暖灰石材、烟熏木、米白织物、深色金属；空间更沉稳、耐用、适合待客。重点突出入户仪式感、中央长厅轴线、节庆型餐厅、封闭厨房和安静套房。

| 空间 ID | 生成视角与重点 |
| --- | --- |
| `f1-porch` | 入户向内，看玄关柜、换鞋凳与厅堂序列 |
| `f1-hall` | 沿中央长轴取景，强调连续门洞与交通秩序 |
| `f1-living` | 从客厅角部看主沙发、电视墙及与餐厅的关系 |
| `f1-dining` | 面向 8 人餐桌与餐边柜，体现聚餐尺度 |
| `f1-kitchen` | 从餐厅看向可关闭厨房，强调满幅透明玻璃门、耐用台面和高效操作线 |
| `f1-stair` | 楼梯基部视角，突出石材踏步、木扶手和导向照明 |
| `f1-guest` | 客房入口向床区，体现安静、易维护的待客配置 |
| `f1-wet` | 湿区对角视角；不设固定干湿隔断，展示整体防水、找坡、地漏和防滑材料 |
| `f1-primary` | 主卧入口向床与采光面，延续沉稳暖石木质感 |

## 二层风格锁定

“暖木家庭极简”：浅烟熏橡木、暖白墙面、燕麦色织物、低饱和鼠尾草绿；整体比一层更明亮柔和，突出家庭起居、四间卧室、南向阳台和北侧生活阳台。

| 空间 ID | 生成视角与重点 |
| --- | --- |
| `f2-south-balcony` | 从阳台端部看双椅小桌与室内起居厅联系 |
| `f2-lounge` | 从楼梯侧看弧形沙发朝南阳台，形成家庭核心 |
| `f2-west-south` | 卧室入口看床、书桌与南向采光 |
| `f2-west-north` | 看床区及通往生活阳台的动线 |
| `f2-life-balcony` | 洗衣、晾晒、清洁收纳一体化工作阳台 |
| `f2-stair` | 二层平台看楼梯口、护栏与起居厅衔接 |
| `f2-ne-bedroom` | 可变卧室，兼顾睡眠、书桌和储物 |
| `f2-wet` | 北侧湿区，强调紧凑分区与柔和防水材料 |
| `f2-primary` | 主卧斜角广角，体现更轻盈舒适的私密氛围 |

## 输出位置

- 一层：`example/output-html/room-renders/floor-1/`
- 二层：`example/output-html/room-renders/floor-2/`
- HTML 内嵌版：`example/output-html/room-renders/embedded/`

## 三层整体精装鸟瞰补图

- 工具：内置 ImageGen。
- 几何参考：`floor3Plan.webp` 是唯一平面几何事实；`floor3PreviewBird.webp` 只用于解释原有三层空间骨架。
- 质量参考：一层、二层精装鸟瞰只控制精细度、完整家具、切墙高度、光影与画面留白，不能控制三层布局。
- 风格参考：`floor3FinalLounge.webp` 控制三层暖灰水泥、烟熏木、燕麦织物与克制侘寂气质。
- 最终提示词摘要：生成三层独立的高精度精装 dollhouse 鸟瞰，完整显示家庭厅、书房/游戏房、两间卧室、楼梯、东侧双卫服务带，以及彼此不同的景观阳台、生活阳台和南阳台；禁止厨房、餐岛、四卧布局、串用一二层空间骨架、粗灰模、裁切外轮廓、文字和人物。
- 输出：`example/output-html/room-renders/floor-3/f3-whole-floor-refined.png`，HTML 内嵌 WebP 为 `example/output-html/room-renders/embedded/floor3PreviewBird-refined.webp`。
